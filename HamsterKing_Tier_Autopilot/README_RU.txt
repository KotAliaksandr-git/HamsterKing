HAMSTER KING TIER AUTOPILOT v1.20
================================

Исправление v1.20
------------------
Добавлен второй подтверждённый оттенок маленьких меток зданий. На снимке
от 26.09.2026 метки были видны, но v1.19 не распознавала их и завершалась
с нулём обработанных зданий. Прежний оттенок и распознавание крупных меток
сохранены; требования к размеру меток и точности совпадения цвета не ослаблены.
Исправление дорожных точек из v1.19 включено в эту сборку.

Проверено распознавание по присланному PNG и контрольным кадрам прошлого
сеанса. Полный запуск v1.20 в игре на Windows в среде сборки недоступен.
Распакуйте архив целиком в отдельную папку и запустите нужный START_AUTO_...
В фильтре карты должны оставаться «Статус: Открытые» и только «Тир 1».

Исправление v1.19
------------------
Исправлена остановка при выборе очередного здания, когда после смещения карты
программа не находила пару дорожных точек с фиксированным сдвигом вправо-вниз.
Теперь каждое место для клика проверяется отдельно; вторая точка подбирается
по фактическому расположению дороги. Цветовые допуски и защитный запас вокруг
каждого клика сохранены. Область поиска ограничена слева от правой панели.
Обе точки должны подтвердиться на трёх последовательных кадрах.
Их координаты записываются в журнал; снимки до/после выбора здания сохранены.
Если подходящих точек нет, программа по-прежнему безопасно останавливается.

Распакуйте весь новый архив в отдельную папку и запустите нужный START_AUTO_...
Для запуска после предыдущей остановки закройте панель здания вручную:
на экране должна остаться карта с метками. Управление: F8 — старт/пауза,
F9 — остановка. Пока кликер работает, не перемещайте карту вручную.

Проверка исправления выполнена по PNG из присланного сеанса: все три здания,
включая снимок, на котором v1.18 останавливалась. Полный запуск в игре на
Windows в среде сборки недоступен; рабочий сеанс ещё нужно проверить в игре.

Какие программы нужны
---------------------
- Windows 10 или Windows 11.
- Встроенный Windows PowerShell 5.1
- Google Chrome. 
  При отсутствии winget используйте https://www.google.com/chrome/


Установка из архива
-------------------
1. Нажмите по ZIP правой кнопкой мыши и выберите «Извлечь всё».
2. Откройте полностью извлечённую папку
   HamsterKing_Tier_Autopilot_V1_20_MINIMAL.

Если при запуске в Chrome
выбрана другая вкладка, программа не завершает работу и ничего не нажимает: она
ждёт ручного выбора вкладки Hamster King, обнаруживает её сама и продолжает
запуск. Диагностика после выбора вкладки выполняется автоматически; в рабочих
режимах окно управления возвращается на передний план и ждёт F8.

Автокликер не перебирает вкладки Chrome вслепую. Windows видит вкладки одного
окна Chrome как одно окно, поэтому безопасно выбрать нужную вкладку может только
пользователь. Если вкладка игры уже выбрана, дополнительного ожидания нет.

Три массовых запуска без меню
-----------------------------
- START_AUTO_TO_TIER_4_PLUS.cmd — все видимые здания Тир 1 довести до Тир 4+;
- START_AUTO_TO_TIER_5.cmd — все видимые здания Тир 1 довести до Тир 5;
- START_AUTO_TO_TIER_5_PLUS.cmd — все видимые здания Тир 1 довести до Тир 5+.

Награда распознаётся по оформлению окна и появлению нижней подсказки, без
чтения слов и проверки длины конкретного перевода. Распознавание проверено на
русских скриншотах и английской видеозаписи; выбирать язык в программе не нужно.
Если игра теряет фокус, автокликер ставится на паузу. Вернитесь в игру и
нажмите F8: перед кликом изображение будет проверено заново.

В logs каждый запуск получает отдельную папку run_дата_время.
В ней — полный журнал, снимок ошибки и парные PNG до и после выбора здания,
включая первоначальный выбор. Номер здания совпадает с номером в журнале.
Автоматически остаются последние 5 сеансов и снимки последних 5 зданий
в каждом. Последний сеанс с ошибкой сохраняется дополнительно, если он старше.
Очистка выполняется при следующих запусках; работающие сеансы не удаляются.
При ошибке пришлите целиком последнюю папку run_... из logs.
Старые логи предыдущих версий, лежащие прямо в logs, автоматически не удаляются.
После завершения программы их можно удалить вручную, если они уже не нужны.

Технические границы автокликера
------------------------------
Программа работает только с тем, что видно на экране: делает локальный снимок,
распознаёт нужные цвета и формы, двигает системный курсор и выполняет обычные
левые клики. Она НЕ обращается к DOM страницы, игровым API или сетевому обмену,
не использует Selenium/WebDriver, расширение браузера, внедрение JavaScript,
чтение памяти процесса или подмену запросов.

Со стороны сайта выполняются только обычные интерфейсные действия мышью.
Программа не содержит функций маскировки или обхода обнаружения. Окончательно
подтвердить, как игровые системы классифицируют такой ввод, могут только
разработчики игры.

Требования к экрану
-------------------
- Windows 10 или Windows 11.
- Разрешение экрана 1920x1080, как на исходных скриншотах.
- Масштаб интерфейса Windows 100%.
- Chrome развёрнут на весь рабочий стол, но НЕ в режиме F11.
- Масштаб страницы Chrome 100%.
- Открыта вкладка, в заголовке которой есть «Hamster King».
- Открыт нужный исследуемый район карты.
- В фильтре установлено «Статус: Открытые» и включена только галочка «Тир 1».
- Перед обычным запуском не должно быть открытых окон исследования, боя или
  награды.

Подготовка игры перед обычным запуском
--------------------------------------
1. Откройте Hamster King в Google Chrome и разверните Chrome на весь рабочий
   стол. Не включайте полноэкранный режим F11.
2. Откройте на карте именно тот исследуемый район, здания которого нужно
   обработать.
3. Откройте фильтр зданий.
4. В поле «Статус» выберите «Открытые».
5. В списке тиров оставьте включённой только галочку «Тир 1». Галочки других
   тиров отключите.
6. Закройте фильтр и проверьте, что на карте видны метки открытых зданий Тир 1.
7. Закройте окна конкретного здания, исследования, боя и награды. На экране
   должна остаться только карта с метками.
8. Убедитесь, что ресурсов достаточно для всех выбранных переходов.

Программа не открывает район и не настраивает фильтр сама. Она обрабатывает
только метки Тир 1, видимые в подготовленной области карты.


Управление
----------
F8 — начать, поставить на паузу или продолжить.
F9 — аварийно прекратить работу.

Если вы переключились на другое окно, программа автоматически ставится на
паузу. Вернитесь к карте и нажмите F8 для продолжения.
